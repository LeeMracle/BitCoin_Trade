| 항목 | 상태 | 무엇을 기다리나 |

### 하면 안 되는 것

- ❌ **파라미터 변경** — 155일간 14회 바꿨고, 한 번도 15 거래가능일을 고정으로 넘긴 적이 없다
- ❌ 레짐 게이트 완화 — 2026-05-03 해제 전례에서 승률 17.4% · PF 0.29 · 누적 **-111%**
- ❌ 표본 누적 중 승률 보고 중간 판정 — 한 세션에서 50%→33%→40% 로 흔들린 이력(다중검정)
- ❌ 수익률 부호로 판정 — 필요 표본 68 ~ 1,064건

### 대기 중 안전한 작업 (표본에 영향 없음)

- 판정 "실패" 대비 **거래소 사전조사** — 업비트는 현물 전용이라 하락장 수익 수단이 원천 부재
- 문서·관측성 정비 (코드 동작 불변 범위)

## 5. 판정 트리거와 그 다음 분기

| 시점 | 기준 | 조치 |
| ---: | --- | --- |
| n=30 | 실행 검증만. 성과 판정 **안 함** | 결함 있으면 수정 후 표본 리셋 |
| **n=50** | 승률 95%CI **상한** < 56.3% | **개선 필요 확정** → 구조 논의 착수 |
| n=150 | 승률 95%CI **하한** > 56.3% | **정상 확인** → 현행 유지 |

손익분기 승률 **56.3%** = `10 / (7.75 + 10)` — TP 사다리(+5.5%/+10%)와 하드손절(-10%)이
정하는 값이라 표본 0건으로 계산된다. 백테스트 62.6~65% 대비 **여유 6~9%p뿐**.

```
                 n=50 도달
                     │
     ┌───────────────┼───────────────┐
     ▼               ▼               ▼
 CI상한<56.3%    56% 근처         승률 충분
     │               │               │
  개선 필요       n=150까지      n=150에서
   확정           계속 누적       정상 확인
     │
     └─→ ⚠ 파라미터 튜닝이 아니라 구조 변경 논의
         (거래소 변경 / 하락장 수익원 / 회전율)
         — 셋 다 파라미터로는 도달 불가
```

### 기대치 (재보정됨)

백테스트가 실제로 주장하는 값은 **달력 월 +1.31%** 이고, 최근 레짐 개방률
(180일 6.1% / 1년 21.4%)을 곱하면 **달력 월 +0.24 ~ +0.83%** 다.
**"월 5%" 는 이 구조가 한 번도 주장한 적 없다** — 현물 전용(숏 불가) + 레짐 게이트 +
TP 사다리가 만드는 구조적 상한이다. 근거: [research/20260831_2](../workspace/research/20260831_2_why_no_profit_yet.md)
