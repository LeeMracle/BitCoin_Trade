# ADR 20260824-1 — TP1 익절선 +5% → +5.5% (부분 익절 50% 유지)

- **일자**: 2026-08-24
- **상태**: 승인 (사용자 결정)
- **발의**: 사용자 — "5% 수익 내면 익절해서 수익 누적, 수수료 포함해 5.5%에 매도"
- **근거 측정**: [workspace/research/20260824_1_tp55_evaluation.md](../../workspace/research/20260824_1_tp55_evaluation.md)

---

## 1. 결정

`services/execution/config.py`

```python
TP_LEVELS = [
    {"trigger_pct": 0.055, "sell_ratio": 0.50},  # +5.5% → 50% 매도
    {"trigger_pct": 0.12,  "sell_ratio": 0.50},  # +12% → 50% 매도 (잔여 0)
]
```

**부분 익절(50%)은 유지**한다. 전량 익절이 아니다.

---

## 2. 근거

### 채택 근거 — 수수료 산술

업비트 현물 수수료 0.05% × 2(매수·매도) = 0.1%.
+5.0%에 팔면 실수령 약 +4.9%로 목표에 미달한다. +5.5%에 팔아야 순 +5%가 남는다.
**익절선의 의미를 "표시 수익률"이 아니라 "실수령 수익률"로 정렬한다.**

### 반대 근거 — 측정상 개선 없음 (기록)

| 설정 | IS 평균 | OOS 평균 | OOS 표준편차 | 거래 | 승률 |
|---|---:|---:|---:|---:|---:|
| 기존 5%/50% + 12% | -18.9% | +0.5% | 5.1% | 57 | 53.6% |
| **채택 5.5%/50% + 12%** | **-20.0%** | **+2.3%** | 5.3% | 57 | 55.6% |
| 5.5% 전량 | -27.5% | +2.2% | 4.0% | 82 | 66.1% |
| 15% 전량 (대조) | -13.3% | **+17.0%** | 6.6% | 50 | 48.6% |

- OOS 차이 +1.8%p는 표준편차 5.1%(20회 평균의 표준오차 ≈ 1.2%p) 대비 **약 1σ** — 신호가 아니다
- IS에서는 오히려 1.1%p **열세**로 방향이 일관되지 않는다
- 즉 이 변경은 **해롭지 않지만 성과 개선을 기대할 근거도 없다**

사용자에게 위 데이터를 제시하고 대안(현행 유지 / 15%로 변경 / 추가 측정)을 함께
제안했으며, 사용자가 원안(5.5% 부분 익절)을 선택했다. 수수료 명료성이라는 판단 기준을
성과 최적화보다 우선한 결정으로 기록한다.

### 기각한 대안

| 대안 | 기각 사유 |
|---|---|
| **5.5% 전량 익절** | IS에서 부분 대비 7.5%p 열세(-27.5% vs -20.0%), OOS 동률. 승자를 더 강하게 잘라내는 방향이라 측정과 반대 |
| **현행 유지** | 사용자가 수수료 명료성을 우선하기로 결정 |
| **TP1 15%로 지연** | 측정상 가장 우수(IS -13.3% / OOS +17.0%)하나 승률이 54%→49%로 하락. 사용자가 이번에는 선택하지 않음 — **미해결 안건으로 남긴다**(아래 §5) |

## 3. 영향 범위

| 대상 | 영향 |
|---|---|
| `_check_tp_levels` | TP1 트리거가 +5% → +5.5%. 코드 변경 불필요(config 상수 참조) |
| 기존 보유 JUP/TAIKO/POL | `tp_sold_levels: [0]` — TP1 이미 완료. 재발동 없음 |
| 기존 보유 OP | `tp_sold_levels: []` — 이제 +5.5%에서 TP1 발동 |
| 백테스트 스크립트 5종 | `C.TP_LEVELS` 참조 — 자동 반영 |
| 검증 기준선 | **리셋** (§4) |

### 알려진 불일치 — ML 라벨 기준 (변경하지 않음)

`services/ml/config.py:29` `LABEL_TARGET_PCT = 0.05` 는 ML 게이트가 학습한
"+5% 도달 확률"의 라벨 기준이다. TP1이 5.5%가 되면서 **0.5%p 어긋난다.**

그럼에도 **바꾸지 않는다**:

- 이 상수를 바꾸면 데이터셋 재구축 + 모델 재학습이 필요하다
- 현재 운영 threshold(0.45)는 5% 라벨로 보정된 값이다. 재학습 없이 상수만 바꾸면
  threshold가 무보정 상태가 되어 지금보다 나빠진다
- ML 게이트는 **진입 전 필터**이지 청산 규칙이 아니므로, 0.5%p 라벨 차이는
  필터 보정을 미세하게 흔들 뿐 동작을 깨지 않는다

→ ML 모델 재학습 시 함께 정렬할 것. 그때까지 문서화된 한계로 둔다.

## 4. 검증 기준선 리셋

ADR 20260823-1의 규칙("파라미터를 바꾸면 서로 다른 전략의 성적을 합산하게 된다")에 따라
`strategy_start`를 **2026-08-24**로 이동한다.

리셋 비용은 **1건**(2026-08-24 SPK/KRW +9.18%, lessons #45 backfill로 기록).
표본이 1건일 때가 리셋 비용이 가장 싼 시점이었다.

- `strategy_start` 2026-08-23 → 2026-08-24
- `consec_loss_floor_date` 동반 이동 (lessons #38 — 두 산정 함수 모두 같은 창)
- `regime_open_days` → 0
- `closed_trades` 27건은 **보존** (창만 이동)

목표치(승률 48% / 평균 +0.75% / 최종 30건)는 유지한다 — TP1 0.5%p 이동으로
백테스트 실측 하한이 유의하게 달라지지 않는다(위 §2 표).

---

## 5. 미해결로 남기는 것

**TP1을 늦추는 방향(15%)이 두 창 모두에서 크게 앞선다**는 측정은 이 ADR로 해소되지 않는다.

| | IS | OOS | 승률 |
|---|---:|---:|---:|
| 채택안 5.5% | -20.0% | +2.3% | 55.6% |
| 15% 전량 | -13.3% | +17.0% | 48.6% |

또한 **어느 설정도 IS에서 양수가 아니다**(-13.3% ~ -27.5%). TP 조정만으로는
포트폴리오 단위 수익성 문제(ADR 20260823-2)가 해결되지 않는다.

08-23 탐색에서 IS·OOS 동시 양수였던 조합은 **슬롯15+TP15%**(IS +3.3% / OOS +15.2%)와
슬롯10+TP15% 둘뿐이었다. 두 측정이 독립적으로 같은 방향을 가리킨다.

→ 실거래 표본 30건 도달 후 재논의 대상.
