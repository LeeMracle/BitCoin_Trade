# ADR 20260917-1 — 3연패 쿨다운 결함: 검증 표본 처리

- **작성일(KST)**: 2026-09-17 12:40 (13:05 근거 정정)
- **상태**: 결정 B — 결함 수정 배포 완료(03:18 UTC, 서버 md5 일치)
- **결정 이력**: 사용자 B(표본 유지) 선택 → **선택 근거였던 반사실이 불완전**(09-14 1건만 조사)함을 같은 세션에서 적발 → 재결정 요청
- **관련**: [lessons #51](../lessons/20260917_1_consec_immediate_path_literal.md) · [ADR 20260907-1](20260907_1_validation_baseline_reset_0902.md)(직전 리셋) · [판정 기준](../strategy_improvement_criteria.md) §3-1

## 배경

09-17 진단에서 검증 창(`strategy_start` 2026-09-02) 표본이 **53건으로 판정선 n=50 을 넘은 상태**였고,
동시에 L1(실행) 결함이 발견됐다: 매도즉시 경로가 사양(5연패)이 아닌 **3연패**에서 72h 매수 중단을 걸었다.
판정 기준은 "L1 통과 전 L2 를 읽지 않는다" 이므로 판정 전 표본 처리를 결정해야 한다.

## 반사실 — 전수 복원 (closed_trades 결정적 재생)

journal 은 09-11 부터, 파일 로그는 06-03 에서 끊겨 **로그로는 09-02~09-11 을 볼 수 없다.**
`closed_trades`(floor 08-29 02:03, `counts_for_consec_loss`)를 시간순 재생해 두 규칙의 발동을 복원했다.

| 실제 (3연패) | 사양 (5연패) | 차이 |
| --- | --- | --- |
| 09-01 13:15 → **09-04 13:15** | 발동 없음 | **부당 차단 ~61h** (창 내 09-02 00:00~). 창 내 진입 0건 |
| 09-10 00:16 → 09-13 00:16 | 09-10 14:16 → 09-13 14:16 | 부당 차단 14h + **부당 개방 14h** |
| 09-14 00:34 → 09-17 00:34 | 09-14 00:52 → 09-17 00:52 (※) | ±18분 |

**부당 개방 14h(09-13 00:16~14:16)에 진입한 거래 = 사양대로면 존재하지 않을 거래:**
LSK · STEEM · PUNDIX · MTL · BERA · BIGTIME (청산 6건, 표본 53 에 포함) + KNC (보유 중).

※ 연쇄효과: MTL(09-13, 위 6건 중 하나)이 09-14 연패의 첫 손실이므로, 사양 하에서는 09-14 발동 시점도
달라진다. 이후 경로는 결정적으로 복원 불가.

## 영향 요약

- 15일 창 중 **약 75시간(~21%) 부당 매수 차단**, 14시간 부당 개방.
- 표본 53건 중 **6건은 결함이 만든 거래**. 나머지 47건도 "차단 기간에 생기지 않은 거래"만큼 구성이 다르다.
- 체결된 거래의 진입가·청산가·청산사유 자체는 오염되지 않았다(차단은 "어떤 거래가 생기는가"만 바꿈).
- 대조: ADR 20260907-1 의 리셋 사유(#48 진입가, #49 하락장 66h 조기 개방)는 손익 부호에 직접 작용했다.
  이번은 개별 거래 손익엔 작용하지 않으나 **표본 구성(선택)에 작용**한다 — 규모는 #49(66h)와 같은 급이다.
