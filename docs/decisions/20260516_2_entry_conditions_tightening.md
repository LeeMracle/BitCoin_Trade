## 1. 배경

본 ADR은 ADR 20260516-1 (포지션/TP 재설계) 적용 직후 발생한 연쇄 손실을 계기로 진입 신호 자체 품질 문제 진단 결과다.

| 손실 중 -9.5%↓ | **63%** (12/19) | 🔴 |

### 패턴
- **단기 손절** (<1h): GLM 0.4h, META 0.3h, ZIL 0.6h — 매수가가 정점, 가짜 돌파
- **장기 횡보 후 손절**: IN 245h, ALT 109h, FLOCK 67h — BEAR 환경 추세 미발달
- 환경: BTC 117.65M (EMA200 -3.58%, BEAR), F&G 43 중립~약세

## 2. 근본 원인

1. **DC12 돌파 신호 false breakout 비율 매우 높음** — DC50→12 축소로 신호 빈도는 늘었지만 가짜 돌파 비율도 동반 상승
2. **BEAR 환경 추세추종 미작동** — plan 20260503_2에서 "거래 빈도 우선, 백테스트 미달 수용"으로 레짐 필터 OFF한 결정의 부작용 현실화
3. **VOL 필터 1.0배 (평균만)** — 가짜 거래량 돌파 통과
4. **ATR 필터 10% 관대** — 고변동 종목 매수 → 한 봉만에 -10% 도달

## 3. 결정

```python
# services/execution/config.py
REGIME_FILTER_ENABLED = True   # False → True (BTC<EMA200 시 매수 차단)
VOL_FILTER_MULTIPLIER = 1.5    # 1.0 → 1.5 (가짜 거래량 차단)
MAX_ATR_PCT = 0.07             # 0.10 → 0.07 (고변동 종목 차단)
```

기존 ATR×3.0 트레일링 + 하드 손절 -10% 캡 + 일일손실 한도는 그대로 유지.

## 5. plan 20260503_2 원복

본 ADR은 plan 20260503_2 (5/3 거래 빈도 우선 결정)을 사실상 원복한다:
- 5/3 결정: REGIME OFF + VOL 1.0 + ATR 0.10 + MIN_VOLUME_KRW 3억
- 결과 (5/3~5/16, 약 2주): 승률 17.4%, PF 0.29, 누적 -111%
- 5/3 결정의 전제(거래 빈도 우선)는 작동 안 함 — 빈도는 늘었지만 손실 누적
- 5/16 본 ADR: REGIME ON + VOL 1.5 + ATR 0.07 — 백테스트 안전선 복귀

MIN_VOLUME_KRW 3억은 유지 (종목 풀 축소는 별도 사안).

## 7. 운영 가드

- **즉시 효과**: BTC<EMA200 (-3.58%)이므로 신규 매수 대부분 차단 예상
- **1주 후 평가** (5/23): 매수 건수 + 진입한 매수의 손절율 측정
  - 매수 0건 + BTC 여전히 BEAR → 정상 (BULL 전환 대기)
  - 매수 발생 + 손절율 < 50% → 효과 확인
  - 매수 발생 + 손절율 ≥ 50% → 추가 보수화 또는 전략 자체 재검토
- **롤백 트리거**: 1개월 매수 0건 + BTC BULL 전환 후에도 매수 0 → VOL/ATR 임계 완화
