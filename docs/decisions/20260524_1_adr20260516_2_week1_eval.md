### Q1. 백테스트 vs 실거래 Sharpe drift

- **판정**: drift 임계(>0.5) 평가 불능, 그러나 매수 빈도 자체는 백테스트 분포와 모순 없음

### Q3. 필터별 차단량과 차단 거래 가상 PnL
**가상 PnL 산출 불가** — REGIME이 1단계에서 모두 차단하여 후속 필터(ATR/VOL/ML)는 평가 대상 도달 안 함. 차단된 매수의 가상 PnL을 계산하려면:
1. REGIME OFF였다면 매수했을 종목·시점 시뮬레이션 필요 → 별도 백테스트
2. 또는 SHADOW 매수 로그 (5/16 이후 0행 → 입력 부족)
- **추정**: 5/17~5/24 BTC -2.3% 횡보 + F&G Extreme Fear 진입 → 만약 5/3~5/16 패턴(승률 17.4%, 한 봉 -10% 패턴 63%)이 재현되었다면 **차단된 거래 가상 PnL은 음수일 가능성 ↑** (lessons #11, ADR 20260516-2 §1 진단과 일관)
- **판정**: REGIME 필터 효과는 **간접 추정으로 OK** (직접 측정 불가)

### Q4. 종목별 PnL 편차

## 5. expert 권고

### 5.1 즉시 권고: **옵션 A (현행 유지) + 옵션 B 백테스트 동시 진행**

근거:
1. **ADR 20260516-2 §7 명시 기준에 따라 정상**: "매수 0건 + BTC 여전히 BEAR → 정상 (BULL 전환 대기)" — 일봉 EMA200 gap -5.4%는 명백한 BEAR, 매수 0은 의도된 결과
2. **§7 롤백 트리거 미충족**: "1개월 매수 0건 + BTC BULL 전환 후에도 매수 0" — 현재 1주 + BTC BEAR 지속이므로 롤백 시기상조
3. **plan 20260503_2 회귀 명백한 위험**: 5/3~5/16 결과(승률 17.4%, PF 0.29, 누적 -111%)는 expert가 직접 진단했던 동일 시나리오의 재현 가능성을 의미 — REGIME 완전 OFF는 보수화 원칙 위배
4. **그러나 무한 대기는 비용**: ML SHADOW 학습 입력 정체(Phase B 6/4 재학습), 봇 자체 운영 정당성 약화 — 백테스트 검증 병행 필요
