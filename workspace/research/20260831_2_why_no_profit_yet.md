# 왜 아직 수익이 확인되지 않았나 — 원인 분해

- **일자**: 2026-08-31
- **질문**: "왜 아직도 수익을 내는 전략을 못 찾았나? 5% 이상은 찾을 듯한데"

---

## 0. 결론

**못 찾은 게 아니라, 찾았는지 확인할 기회가 없었다.**

| | |
| --- | --- |
| 백테스트 | **이미 찾았다** — OOS +19.0% (434일, 슬롯15/TP2 10%) |
| 실거래 | **미검증** — 깨끗한 표본 6 거래가능일치뿐 |
| 원인 1 | **레짐 게이트가 최근 180일 중 169일을 닫았다** (개방률 **6.1%**) |
| 원인 2 | **기회가 열린 11일 중 첫 6일에 파라미터를 4번 바꿨다** |
| 기대치 | **"5%/월"은 이 구조가 주장한 적 없는 숫자** — 백테스트 자체가 달력 월 **+1.31%** |

---

## 1. 원인 1 — 거래 기회가 없었다

레짐 게이트(BTC 종가 > EMA200) 개방률:

| 구간 | 개방일 | 개방률 |
| --- | ---: | ---: |
| 최근 90일 | 11 / 90 | 12.2% |
| **최근 180일** | **11 / 180** | **6.1%** |
| 최근 1년 | 78 / 365 | 21.4% |
| 최근 700일 (백테스트 구간) | 370 / 700 | 52.9% |

**최근 90일의 개방일 11일은 전부 최근 11일이다.** 즉 2026-05-20 ~ 08-19 약 3개월간
**단 하루도 거래하지 못했다.** 수익이 안 난 게 아니라 **매매 자체가 없었다.**

> ⚠ 여기서 중요한 함정: 백테스트는 개방률 52.9%인 700일 구간에서 측정됐다.
> 최근 1년은 21.4%, 최근 180일은 6.1%다. **백테스트 구간과 실거래 구간의
> 시장 성격이 다르다.** 백테스트가 낙관인 이유가 생존편향만이 아니다.

## 2. 원인 2 — 열리자마자 바꿨다

전략 파라미터 변경 이력 (인프라·문서 결정 제외):

```
2026-03-29  일봉 -> 단타 전환
2026-04-26  DC 50 -> 15                     (+28d)
2026-05-04  부분익절·거래량필터·일일손실한도    (+8d)
2026-05-04  ML 신호 필터                      (+0d)
2026-05-05  DC 15->12, ATR, VOL 동시 튜닝     (+1d)
2026-05-05  ML LIVE 가속                      (+0d)
2026-05-16  TP 3단계 -> 2단계, 사이징 재설계   (+11d)
2026-05-16  레짐필터 재활성화 + VOL + ATR      (+0d)
2026-05-24  레짐 갭 임계                      (+8d)
2026-06-07  MIN_VOLUME 3억 -> 5억             (+14d)
2026-08-23  비중 상한 0.20 도입               (+77d)  <- 이 77일은 레짐 폐쇄 구간
2026-08-24  TP1 5% -> 5.5%                   (+1d)
2026-08-24  TP2 12% -> 10%                   (+0d)
2026-08-25  슬롯 5 -> 15                     (+1d)
2026-08-31  (현재 — 6일째 무변경)
```

**155일간 14회 변경, 중앙값 6일.** 최장 무변경 77일은 레짐이 닫혀 있어
어차피 거래가 없던 구간이다.

레짐이 2026-08-20 에 열렸고, **그 직후 08-23·24·24·25 에 4번 바꿨다.**
기회가 오자마자 기준선을 리셋한 셈이다.

### 왜 이게 치명적인가

판정에 필요한 표본은 **n=50(개선필요) / n=150(정상확인)** 이고
([판정 기준](../../docs/strategy_improvement_criteria.md)),
레짐이 열려 있을 때 축적 속도는 **3.3건/일**(실측 20건/6일)이다.

| 판정선 | 필요 거래가능일 | 개방률 100% | 개방률 21.4% | 개방률 6.1% |
| --- | ---: | ---: | ---: | ---: |
| n=50 | 15.2일 | 15일 | 71일 | 248일 |
| n=150 | 45.5일 | 45일 | 212일 | 745일 |

**한 번도 15 거래가능일을 파라미터 고정으로 넘긴 적이 없다.**
즉 이 전략은 **실패한 게 아니라 채점된 적이 없다.**

## 3. 기대치 재보정 — "5%"는 어디서도 나온 적 없는 숫자

백테스트가 실제로 주장하는 값:

```
OOS +19.0% / 달력 434일 / 거래가능 147일
  -> 거래가능 30일당  +3.88%
  -> 달력 1개월당     +1.31%
```

개방률을 곱하면 달력 기준 기대치는:

| 개방률 가정 | 달력 월 기대 |
| --- | ---: |
| 최근 180일 (6.1%) | **+0.24%** |
| 최근 1년 (21.4%) | +0.83% |
| 백테스트 구간 (52.9%) | +2.05% |

**그리고 이 값들은 생존편향 할인 전이다.**

즉 **월 5%는 이 전략 구조가 한 번도 주장한 적 없다.** 이유는 구조적이다:

1. **현물 전용 — 숏 불가.** 하락장에서 수익 기회가 원천적으로 없다.
2. **레짐 게이트** — 상승장에서만 거래. 기회의 6~21%만 사용.
3. **TP 사다리가 승자를 자른다** — 완주 승자 +7.75%, 완주 패자 -10%.
   손익분기 승률 **56.3%**, 백테스트 62.6~65% 대비 **여유 6~9%p뿐**.

### 이미 시도했고 실패한 방향

"더 자주 거래하자"는 이미 해봤다. 2026-05-03 [plan 20260503_2](../plans/20260503_2_enable_trading_in_bear.md)
에서 레짐 필터를 **해제**했고, 결과는 5/3~5/16 승률 17.4% · PF 0.29 · **누적 -111%**
(손실 중 63%가 하드손절 직행). ADR 20260516-2 로 원복했다.

**게이트를 여는 것은 기회를 늘리는 게 아니라 손실을 늘렸다.**

## 4. 그래서 지금 무엇을 해야 하나

**지금이 5개월 만에 처음 온 기회다** — 레짐 11일 연속 개방, 현재 100%.

| 할 것 | 이유 |
| --- | --- |
| **파라미터 동결** | 이미 6일째 무변경. n=50 까지 **9 거래가능일** 남았다 |
| 실행 결함 0 유지 | L1 이 통과해야 L2(성과)를 읽을 수 있다 |
| n=50 에서 판정 | 승률 CI 상한 < 56.3% 면 개선 필요 확정 |

| 하지 말 것 | 이유 |
| --- | --- |
| 파라미터 조정 | 표본이 리셋된다. 14번 반복한 실수 |
| 레짐 게이트 완화 | -111% 전례 |
| 승률 보고 중간 판정 | 다중검정. 이번 세션에만 50%→33%→40% |

**약 2주 안에 처음으로 "이 전략이 되는가"의 답이 나온다** — 레짐이 유지되면.

## 5. 기대치를 올리려면 구조를 바꿔야 한다

파라미터 조정으로는 월 5%가 나오지 않는다. 나오려면 셋 중 하나다:

| 방향 | 검토 상태 |
| --- | --- |
| **레버리지/선물** | 업비트 현물 전용 — 거래소 변경 필요. 리스크 급증 |
| **하락장 수익원** | 숏 불가. 현금 보유가 유일한 방어 |
| **회전율 증가** | 게이트 완화 = 실패 전례. 단타 전환도 2026-03-29 실패 |

**어느 것도 파라미터 튜닝이 아니다.** 지금 전략의 상한을 먼저 확인하고
(n=50~150), 그 값이 목표에 못 미치면 그때 구조를 논의하는 순서가 맞다.
