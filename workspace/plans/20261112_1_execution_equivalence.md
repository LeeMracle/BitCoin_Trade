- **관련**: [ADR 20261112-1](../../docs/decisions/20261112_1_universe_btc_eth_staged_reenable.md) · [research 20261112_1](../research/20261112_1_universe_reduction_result.md) · ADR 20261107-1 · lessons #1 #6 #26 #4 #19

## 1. 목표

백테스트(U2-S1)가 가정한 실행과 서버 봇의 실제 실행이 **같은지**를 검증한다. 질문은 두 개뿐이다.
1. 봇이 매일 계산하는 DC12 상단·레짐·ATR 이 백테스트 코드와 일치하는가 (단계 0)
2. 틱 돌파 → 시장가 체결의 실제 진입 슬리피지가 **0.2% 미만**인가 (단계 1)

**이 plan 은 전략 수익성을 판정하지 않는다.** 단계 1 손익은 보고만 한다.

## 2. 성공기준 (사전 고정)

### 단계 0 — 섀도 (주문 없음, `BUY_DISABLED=True`)
- [ ] 14일 연속, 매일 BTC·ETH 각각 `dc_upper · ema200 · atr14 · regime` 이 백테스트 재계산값과 일치 — 허용 오차: 가격 레벨 상대오차 ≤ 1e-4, regime 불일치 **0건**
  - 백테스트 쪽은 **전일 종가 기준**(cto M1 수정판)으로 계산하고, EMA 는 실거래와 같은 **250봉** 창으로 맞춘다(cto M2) — 비교 대상은 "실거래가 계산해야 할 값"이다
- [ ] 레벨 산출 시각이 UTC 00:00 봉 마감 후 10분 이내 (lessons #1 — 진행 중 봉 미사용)
- [ ] `pre_deploy_check` 신규 룰 3개 PASS (화이트리스트 외 진입 경로 부재 AST · 비중×슬롯 ≤ 0.95 · 문서 동기화)

### 단계 1 — 최소주문 (10,000원/건, `MICRO_ORDER_MODE=True`)
- [ ] 신호 **5건** 체결. 각 건에 트리거 틱가·주문 시각·체결가·슬리피지 기록
- [ ] 평균 진입 슬리피지 **< 0.2%** (중단선: ≥ 0.2% 즉시 중단) · 최대 단일 건 < 0.5%
- [ ] L1 일치 5/5: 진입가·손절/TP 트리거·수량 회계가 [research 20261030_1](../research/20261030_1_l1_execution_audit.md) 방식으로 체결 내역과 일치
- [ ] 백테스트 동일 구간 재현: 해당 5건을 백테스트 코드에 같은 날짜로 넣었을 때 **신호 발생 일치 5/5** (봇이 잡은 신호를 백테스트도 잡는가, 역도 성립하는가)
- [ ] TP1 50% 부분청산이 최소주문 제약으로 실패한 건 0

### 단계 1 → 2 전환 조건
- 위 전수 충족 + Master 승인 (ADR §7 기록). 수익률은 조건이 아니다.

## 4. 리스크 & 사전 확인사항

- **지금 BEAR** — 단계 1 신호는 BULL 복귀 전 0건. 단계 0 은 레짐과 무관하게 진행. 90일 상한 내 5건 미달 시 "기간 만료"로 보고하고 연장은 Master 결정
- **슬리피지 측정 편향**: 10,000원 주문은 0.475 비중(약 12만원)보다 호가 충격이 작다. BTC·ETH 1호가 두께(수천만원)에 비해 둘 다 무시 가능 — 측정 대상은 호가 충격이 아니라 **틱→주문 지연 중 가격 이동**이며 이는 금액과 무관. 결과 문서에 명시
- **부분청산 최소주문**: TP1 50% = 5,000원 → `MIN_ORDER_KRW` 와 동일, 가격 하락 시 미달 가능 → **`MICRO_ORDER_KRW = 12,000` 확정 (Master 2026-11-12, 여유 20%)**. pre_deploy 룰이 `MIN_ORDER / 최소 매도비율 × 1.2` 하한을 집행
- **lessons #6/#26**: 화이트리스트는 scanner·realtime_monitor·(폐기된) EMA-TREND 경로 전부. 진입점 전수 열거 후 적용
- **lessons #4/#19**: 슬롯·비중·화이트리스트는 config 단일 원천. CLAUDE.md 표는 배포와 같은 커밋
- **lessons #44**: 섀도 비교기는 "일치"가 아니라 "불일치를 잡는가"로 검증
- **cto M1 후속**: `backtest_param_sweep.build_panel` 당일값 lookahead → lessons 기록. 이 함수를 쓴 연구(20261104_1 PIT, 20261103_1 등) 영향 범위를 한 줄씩 적는다 — 결론 뒤집힘 여부만, 재실행은 안 함
- **실거래 영향**: 단계 0 은 0. 단계 1 최대 손실 = 5건 × 600원 = 3,000원
