# 전략 파라미터 탐색 — 포트폴리오 단위 (실거래 미변경)

- **작성일(KST)**: 2026-08-23 11:20
- **예상 소요**: 2시간
- **관련**: [ADR 20260823-2](../../docs/decisions/20260823_2_position_weight_cap.md)

## 1. 목표

ADR 20260823-2에서 "현재 config는 포트폴리오 단위로 수익이 나지 않는다"(무작위 20회
전부 손실, 평균 -16.4%)를 확인했다. **무엇을 바꾸면 달라지는지**를 백테스트로 탐색한다.

**실거래는 건드리지 않는다.** 이 작업의 산출물은 "바꿔야 할 후보와 그 근거"이며,
실제 변경은 별도 ADR + 사용자 승인을 거친다.

## 2. 성공기준

- [ ] 4개 축(슬롯 수 / TP 수준 / 손절·ATR / DC 기간)에 대해 단일요인 민감도 측정
- [ ] 각 조합을 무작위 선택 N회 반복 → 평균·표준편차 보고 (선택편향 제거)
- [ ] **IS/OOS 분리** — 전반부에서 고른 후보가 후반부에서도 유지되는지 확인
- [ ] 시도한 조합 수를 명시 (다중비교 문제 정직하게 기록)
- [ ] "개선 후보 없음"도 유효한 결론으로 수용 — 억지로 찾지 않는다
- [ ] 실거래 config 무변경 확인

## 3. 단계

1. 포트폴리오 엔진을 파라미터화 (`scripts/backtest_param_sweep.py`)
2. 기준선 재확인 (현재 config = ADR 20260823-2 수치와 일치하는지)
3. 단일요인 스윕 — 한 번에 한 축만 변경
4. 상위 후보 2~3개에 대해 IS/OOS 검증
5. 결과 문서화 + 다음 단계 권고

## 4. 리스크 & 사전 확인사항

| 리스크 | 완화 |
|---|---|
| **과최적화** — 조합을 많이 돌리면 우연히 좋은 게 나온다 | 단일요인 우선(격자 탐색 지양), IS/OOS 분리, 시도 횟수 명시 |
| 선택편향 — 진입 후보 선택 순서가 결과를 14%p 좌우 | 무작위 선택 N회 평균으로만 판단 |
| 생존편향 — 상장폐지 코인 누락 | 결과는 낙관 쪽으로 치우침을 명시. 절대수익보다 **상대비교**에 사용 |
| 일봉 근사 — 장중 순서 미상 | 보수(손절 우선) 고정. 필요 시 브래킷 |
| 단일 기간 의존 | IS/OOS + 연도별 분해 병기 |
| **결과를 실거래에 즉시 반영하려는 유혹** | 이 계획의 산출물은 "후보와 근거"까지. 변경은 별도 ADR |

# 결과 (2026-08-23)

## 방법론 수정 1건 (착수 후 발견)

시간 기준 60/40 IS·OOS 분리가 **OOS를 통째로 레짐 폐쇄 구간에 놓았다**
(2026 Q1/Q2 통과율 0%). OOS 거래가 3~16건뿐이라 무의미했다.
→ 분리 기준을 **거래 가능일(레짐 개방일)** 로 변경. 수정 후 IS 214일 / OOS 147일
(거래가능 기준), OOS 거래 36~124건으로 표본 확보.

## 단일요인 결과 (무작위 10회 평균)

| 축 | 결과 | 판정 |
|---|---|---|
| **슬롯 수** | 3→-5.1% / 5→+0.2% / 10→+5.1% / 15→+11.1% (OOS) | **일관 개선** |
| **TP 수준** | 현행 5/12%→+0.7% / 10%→+5.8% / 15%→+10.8% / 없음→+8.1% (OOS) | **일관 개선** |
| 손절·ATR | 7%~20%, ATRx2~4 모두 OOS -4.4%~+3.2% 산발 | 신호 없음 |
| DC 기간 | DC20 IS -0.1% 인데 OOS -7.4%, DC12는 반대 | **IS/OOS 반대 — 과최적화 함정** |

단일요인만으로는 IS·OOS 동시 양수 설정이 없었다.

## 결합 검증 (방향이 일관된 2축만)

격자 탐색이 아니라, 위에서 방향이 일관되게 나온 **슬롯·TP 두 축만** 묶었다.
손절·DC는 근거가 없어 제외.

| 설정 | IS | OOS | OOS MDD | 거래 | 승률 |
|---|---:|---:|---:|---:|---:|
| 현행 (슬롯5 TP5/12) | -18.4% | +0.7% | -18.4% | 56 | 55.2% |
| 슬롯10 + TP없음 | -1.8% | +15.3% | -21.7% | 68 | 47.1% |
| **슬롯10 + TP15%** | **+0.1%** | **+12.4%** | -20.1% | 71 | 47.2% |
| 슬롯15 + TP없음 | -1.0% | +19.4% | -19.8% | 87 | 47.7% |
| **슬롯15 + TP15%** | **+3.3%** | **+15.2%** | -19.3% | 92 | 47.5% |

**승률은 55%→47%로 떨어지는데 수익은 오른다.** TP1(+5%)이 승자를 일찍 잘라
"자주 이기지만 조금 이기고, 질 때는 -10%까지 지는" 비대칭을 만들고 있었다는 뜻이다.

## 정직하게 남길 것

- **시도한 설정 수 26개** (단일요인 21 + 결합 5). 26번 시도해서 2개가 양수인 것은
  강한 증거가 아니다. IS +3.3%는 겨우 양수다.
- 생존편향(상장폐지 코인 누락)으로 절대 수익은 낙관 쪽이다. **상대 비교용**이다.
- 일봉 근사, 손절 우선(보수) 가정 고정.
- 슬롯 15로 늘리면 `MAX_POSITION_WEIGHT = 0.20`이 무의미해진다(1/15 = 6.7%).
  슬롯 변경 시 비중 상한도 함께 재설정해야 한다.
- 슬롯 10→5 축소는 ADR 20260516-1이 **dust 방지** 목적으로 내린 결정이었다.
  현재 자본 254,531원 / 15슬롯 = 슬롯당 약 17,000원, TP15%·50% 매도 시 약 9,800원으로
  최소주문 5,000원은 넘지만 여유가 크지 않다. 되돌리려면 그 근거를 재검토해야 한다.

## 검증 기록

**확인 항목 5개 / 발견 이슈 1개**

확인: 4개 축 단일요인 측정 / 무작위 반복 / IS·OOS 분리 / 시도 수 명시 / 실거래 무변경
이슈: IS·OOS 분리 기준 결함 (시간 → 거래 가능일로 수정)

## 결론 및 권고

단일요인 조정으로는 해결되지 않지만, **슬롯 수와 TP 수준 두 축은 방향이 일관**하고
결합 시 IS·OOS 모두 양수가 된다. 다만 근거의 강도가 "확실한 개선"이라기엔 약하다.

권고: 즉시 실거래 반영보다 **(1) 표본을 넓힌 재검증**(종목 수·기간 확대, 무작위 반복 증가),
**(2) dust·비중상한 등 운영 제약 재계산**, **(3) 별도 ADR + 승인** 순서.
실거래 재검증(ADR 20260823-1)이 0/30건이므로 지금 파라미터를 바꾸면 그 표본도 리셋된다.
