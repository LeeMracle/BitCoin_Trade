## 1. 목표

v1·v2 는 **전략을 바꿔가며** 같은 모집단(업비트 KRW 전 종목 PIT, 대부분 소형 알트)에서 실패했다. 이 plan 은 반대로 **모집단을 바꾼다** — 대형·고유동·장수 종목으로 좁히면 양의 기대값을 내는 전략이 있는가.

질문을 두 개로 분리한다:
1. **현행 전략(DC12)이 실패한 원인이 모집단인가?** → 현행 전략을 축소 모집단에 그대로 적용 (S1)
2. **축소 모집단에 맞는 전략이 있는가?** → 장기 추세추종(S2), v2 에서 유일하게 IS 기대값이 양수였던 NR7(S3)

부수 효과: 모집단이 1~10종목이면 **2017년부터 장기 데이터**를 쓸 수 있어 상승·하락장 여러 사이클로 검증 가능(lessons #2). 메모리 문제(v2 275종목 격자)도 사라진다.

**본 plan 은 사전 등록**이다. 결과를 본 뒤 모집단·전략·파라미터·창·기준을 바꾸지 않는다.

## 3. 전략 (사전 고정 3종 + 벤치마크 2종)

### S1. 현행 DC12 (대조군)
`services/execution/config.py` 현행값 그대로 — DC(12) 시간봉 돌파 진입, ATR(14)×3.0 트레일 + 하드 -6%, TP1 +5.5% 50% / TP2 +10%, 레짐 필터 BTC>EMA200, `MAX_ATR_PCT` 0.07, `VOL_FILTER` ×1.5.
- 목적: "모집단만 바꾸면 현행 전략이 살아나는가". 기존 엔진(`backtest_param_sweep.build_panel` + `backtest_stop_validation.simulate`) 재사용, 슬롯·비중만 §2 로.

### S2. 장기 추세추종 (일봉 채널, Turtle System 2 형)
- 진입: **일봉 종가 > 직전 55일 최고 종가** → 다음 일봉 시가
- 청산 1: **일봉 종가 < 직전 20일 최저 종가** → 다음 일봉 시가
- 청산 2 (손절): 진입가 − **2 × ATR(20, 일봉)** — 시간봉 경로로 판정
- 익절·시간청산·레짐 필터 **없음** (추세 자체가 필터)
- 파라미터 고정: `entry=55, exit=20, atr=20, stop_mult=2.0`
- 근거: 장기 채널 추세추종은 BTC 등 고유동 자산에서 다수 보고된 고전 규칙. **모든 신호가 일봉 종가 확정 후** 다음 시가 집행 — EMA-TREND 실패 원인(실시간 틱 실행, lessons #1)을 구조적으로 배제.

### S3. NR7 압축 돌파 (v2 A3 와 동일 규칙·파라미터)
`nr_period=7, tp=+8%, sl=-3%, max_bars=3` — v2 에서 IS 건당 +0.31% 였으나 IS-A 불안정으로 탈락. 이번엔 **다른 모집단·다른 창**이므로 v2 IS 재사용이 아니다.

### 벤치마크 (판정 기준에 사용, 선택 대상 아님)
- **B0 보유**: 모집단 동일가중 매수 후 보유
- **B1 레짐 보유**: 각 종목을 일봉 종가 > EMA200 일 때만 보유 (다음 시가 집행)

## 5. 성공 기준 (사전 고정 — v2 설계 결함 반영)

v2 cto review 의 두 설계 입력을 반영한다:
- **고정 승률 기준 폐기** → 아키텍처마다 손익구조가 달라 승률 하나로 비교할 수 없다. **기대값·Profit Factor·Sharpe 중심**
- **Guards OFF 를 1차 측정** → 운영 안전장치(서킷·연패 쿨다운)가 표본을 잘라내 전략 성적을 가린다. Guards ON 은 별도 보고만

### 5-1. IS (셀 선택)

| 지표 | 기준 |
| --- | --- |
| IS 건당 기대값 (수수료 0.1% 왕복 + 손절 슬리피지 0.15%) | **> 0** |
| IS Profit Factor | **≥ 1.3** |
| IS Sharpe (일간 자본곡선, 연 365) | **≥ 0.8** |
| IS 거래 수 | **≥ 30** (U1 S2 같은 저빈도 셀 고려) |
| **분할 안정성** IS-A · IS-B 각각 | 건당 > 0 AND PF ≥ 1.1 AND 거래 ≥ 10 |

**선택**: 전 기준 통과 셀 중 **IS Sharpe 최대** 1개 (빈도가 다른 셀을 공정하게 비교하려고 v2 의 '건당 최대' 대신 Sharpe).
**통과 0개 시**: 시나리오 B — §8.

### 5-2. OOS (선택 셀 1회)

| 지표 | 기준 |
| --- | --- |
| OOS Sharpe | **≥ 0.8** |
| OOS MDD | **≥ -15%** (→ §9 결정 ②) |
| OOS 건당 기대값 | **> 0** |
| OOS Profit Factor | **≥ 1.2** |
| OOS 거래 수 | **≥ 20** |
| IS → OOS Sharpe 하락폭 | **< 50%** |
| **보유 대비** | OOS Sharpe ≥ 같은 모집단 B0 OOS Sharpe × 0.8 — "그냥 들고 있는 것보다 위험조정 성과가 크게 못하면" 매매할 이유가 없다 |

7개 전수 충족 시 **OOS 통과**. 조건부·완화 금지.

### 5-3. 보조 보고 (판정 불포함)
- Guards ON 재실행 결과 (운영 재현)
- U3 상폐 보정: 상위 수익 거래 15% → -15% 치환 (v1·v2 와 동일 규칙)
- 승률·Wilson CI (seed 평균 n 기준), 청산 사유 구성, 보유시간
- 연도별 수익 — 특정 연도 몰빵 여부

### 5-4. 통계적 한계 (사전 명시)
U1 S2 같은 저빈도 셀은 OOS 거래 20~40건 수준으로 예상 — 승률 CI 로는 판정 불가. 그래서 승률이 아닌 기대값·PF·Sharpe·분할 안정성을 쓴다. 통과해도 "통계적 확정"이 아니라 **"페이퍼 트레이딩 진입 자격"** 이다.

## 9. ⚠ 승인 시 결정 필요 (Master)

**① 포지션 크기** — 종목당 `0.95/|U|` (U1 은 자본 95% 를 BTC 하나에). 현행 상한 0.10 을 유지하면 U1 은 자본 90% 가 놀아 수익·MDD 모두 1/10 이 되고, 축소 모집단의 의미가 없다.
- 추천: **`0.95/|U|` 로 백테스트** (통과 시 실거래 적용은 별도 ADR 에서 다시 결정)

**② OOS MDD 기준 -15%** — 단일 자산 추세추종은 역사적으로 MDD -25 ~ -40% 가 흔하다. U1·U2 에서는 기준 자체가 사실상 통과 불가일 수 있다.
- 추천: **-15% 유지**. 현 자본(약 26만원)과 서킷 -20% 설계에 맞춘 리스크 한도이며, 결과를 본 뒤 완화하는 것은 금지다. 낮추고 싶다면 **지금(사전 등록 전)** 정해야 한다
