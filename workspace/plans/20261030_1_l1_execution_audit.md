## 3. 검사 항목 — 사전 고정

| # | 무엇 | 방법 | 판정 |
| --- | --- | --- | --- |
| C1 | 진입가 = 실제 매수 체결가 | 거래소 매수 주문(canceled 포함, lessons #43) 평균 체결가 vs `entry_price` | 괴리 ≤ 0.5% |
| C2 | 기록 수익률 = 실제 체결 손익 | 진입~청산 사이 매도 체결 전수(`fetch_order` 재조회)로 money-weighted 재계산 vs `return_pct` | 차이 ≤ 0.3%p |
| C3 | 손절 캡 준수 | 손실 거래의 실현 손실 vs 캡(신규 -6% / 기존 -10%) | 손실 ≥ -(캡+1.0%p). 초과 시 원인(갭·지연) 분류 |
| C4 | TP 집행 | 매도 체결가 중 TP1(+5.5%)·TP2(+10%) 트리거 이후 체결 여부, 비율 50/50 | 트리거 미만 체결가 괴리 ≤ 1.0%p, 수량 비율 45~55% |
| C5 | 진입 조건 | 진입 시점 로그의 돌파 신호 존재 + 레짐 BULL + 동일 종목 중복 진입 없음 | 신호 로그 존재. 로그 보존 밖이면 판정불가 |
| C6 | 슬롯/비중 | 진입금액 / 당시 총자산 ≤ 0.10(+반올림 여유 0.5%p), 동시 보유 ≤ 15 | 위반 0 |
