## 1. 목표

실거래 신규 45건 중 41건이 백테스트 종목군 밖이었다. 실거래와 같은 규칙으로 날짜별 종목군을 만들어
현행 전략(SL6)의 기대치를 다시 재고, 그 위에서 개선 후보 3개를 IS 선택 → OOS 1회 검증한다.

## 2. 성공기준

- [x] 시점 일치 종목군(PIT) 규칙 구현: 그날 **전일 거래대금(종가×거래량) ≥ 5억** AND **첫 일봉 이후 67일 이상**(실거래 `min_bars` = DC12 + 추세 50 + 5)
- [x] 같은 기간·같은 IS/OOS 경계에서 OLD40(기존 종목군) vs PIT 의 SL6 기준선 비교표
- [x] 후보 A·B·C 를 아래 사전 고정 규칙으로 판정하고 결과 기록
- [x] 기존 동작 불변: `build_ctx(allow=None)` 기본값으로 기존 테스트 통과

## 3. 사전 고정 — 결과를 본 뒤 바꾸지 않는다

| 후보 | 내용 | 구현 |
| --- | --- | --- |
| A 종목 제한 | 첫 일봉 이후 **180일 이상** 종목만 | `allow` 에 나이 조건 추가 |
| B 변동성 상한 | 진입 ATR% 상한 **7% → 5%** | `P(max_atr=0.05)` |
| C 돌파 확인 | 시간봉 **종가**가 돌파선 위에서 마감한 다음 시간봉 시가에 진입 | `build_ctx(confirm_close=True)` |

**선택 규칙 (IS 만 본다)**: IS 승률 ≥ 48.6%(손익분기 43.6% + 5%p) 이고 IS 거래 수 ≥ PIT 기준선의 30% 인 후보 중 IS 건당 수익이 가장 큰 1개.
**채택 규칙 (OOS 1회)**: 선택안의 OOS 건당 > PIT 기준선 OOS 건당 AND OOS 승률 ≥ 43.6%. 아니면 "개선안 없음".
**기준선 해석**: PIT 기준선 IS·OOS 승률이 모두 48.6% 미만이면 "현행 전략은 실거래 종목군에서 여유가 없다"가 백테스트로 확인된 것.

## 5. 리스크 & 한계

- **상장폐지 종목은 업비트 API 로 받을 수 없다** → 생존편향이 남는다(낙관 방향). 결과는 상한으로 읽는다
- **정정(결과 확인 전, 21:50)**: 상장 기준 22일 → 67일. 22일은 `scanner.MIN_LISTING_DAYS` 였으나 실시간 봇은 `realtime_monitor` 의 `min_bars`(67봉)로 편입한다
- **발견**: `fetcher._fetch_range` 가 조회 시작 200일 뒤 상장한 코인을 0봉으로 반환 — 기존 백테스트 전부에서 최근 상장 코인이 빠졌다. 수정 + `tests/common/test_fetcher_late_listing.py`. 실거래(92일 조회)는 첫 페이지 안이라 무영향
- 거래대금은 종가×거래량 근사 (실거래는 24h 롤링 quoteVolume)
- 업비트 rate limit — fetch_hourly 의 0.11s sleep · 재시도 유지
- 봇 운영과 무관 (로컬 연구, 서버·state 접근 없음)
